title: "Tabs"
description: "Neumorphic tabs on the Radix primitive. The same carved tray as the toggle group: idle triggers sit flat and one raised knob slides to the active one. The line variant keeps the stock underline."
---

## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-tabs.json
```

## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@/components/ui/neu/tabs"
```

```tsx
<Tabs defaultValue="account">
  <TabsList>
    <TabsTrigger value="account">Account</TabsTrigger>
    <TabsTrigger value="password">Password</TabsTrigger>
  </TabsList>
  <TabsContent value="account">Make changes to your account here.</TabsContent>
  <TabsContent value="password">Change your password here.</TabsContent>
</Tabs>
```

## Line

`variant="line"` on `TabsList` drops the tray and marks the active trigger with an underline.

```tsx
<TabsList variant="line">
```

## Vertical

`orientation="vertical"` stacks the triggers and puts the list beside the content; the knob slides vertically and the line variant moves its mark to the inline end.

```tsx
<Tabs defaultValue="account" orientation="vertical">
```
