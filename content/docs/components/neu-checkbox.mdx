## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-checkbox.json
```

## Usage

```tsx
import { Checkbox } from "@/components/ui/neu/checkbox"
```

```tsx
<Checkbox />
```

## Indeterminate

Pass `checked="indeterminate"` to draw a dash instead of the tick, for a parent row that is partly selected.

```tsx
<Checkbox checked="indeterminate" />
```

## Tick

`tick="always"` keeps a faint tick in the empty well to preview the mark. The default, `on-check`, shows it only when checked.

```tsx
<Checkbox tick="always" />
```
