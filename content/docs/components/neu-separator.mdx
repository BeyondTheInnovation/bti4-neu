## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-separator.json
```

## Usage

```tsx
import { Separator } from "@/components/ui/neu/separator"
```

```tsx
<Separator />
```

## Vertical

Use `orientation="vertical"`. It fills the parent's height, so give the row a height.

```tsx
<div className="flex h-5 items-center gap-4">
  <span>Docs</span>
  <Separator orientation="vertical" />
  <span>Blog</span>
</div>
```
