## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-switch.json
```

## Usage

```tsx
import { Switch } from "@/components/ui/neu/switch"
```

```tsx
<Switch />
```

## Size

`size` is `sm`, `default` or `lg`. `lg` is neu-only.

```tsx
<Switch size="sm" />
```
