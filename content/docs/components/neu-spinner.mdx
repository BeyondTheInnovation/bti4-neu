## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-spinner.json
```

## Usage

```tsx
import { Spinner } from "@/components/ui/neu/spinner"
```

```tsx
<Spinner />
```

## Size

`className` styles the icon, so size and color it there. The wrapper carries `role="status"` with an `aria-label` of "Loading"; pass `aria-label` to change it. Under reduced motion it turns slowly instead of stopping.

```tsx
<Spinner className="size-6" aria-label="Saving" />
```
