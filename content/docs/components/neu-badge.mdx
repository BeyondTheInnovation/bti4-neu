## Installation

```bash
bunx --bun shadcn@latest add https://neu.beyondtheinnovation.com/r/neu-badge.json
```

## Usage

```tsx
import { Badge } from "@/components/ui/neu/badge"
```

```tsx
<Badge>Badge</Badge>
```

## As Child

Use `asChild` to render a link with the badge's styles. Outline and ghost tint on hover when the badge is a link.

```tsx
<Badge asChild variant="outline">
  <a href="/changelog">New</a>
</Badge>
```
